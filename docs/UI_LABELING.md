# UI Labeling & Copy Contract (`src/ui/labels.ts`)

This document is the human-readable reference for all user-facing text, Macro-Block captions, badges, placeholders, tooltips, accessibility (`aria-label`) copy, and theme labels in **ScriptFlow (`v1.1.0`)** (Auteur Script Editor & Scene Blueprint).

The programmatic Single Source of Truth (SSOT) for interface copy is exposed through the public facade **`src/ui/labels.ts`**, which composes five domain-split modules under **`src/ui/labels/`** (`meta.ts`, `editor.ts`, `library.ts`, `debug.ts`, `ai.ts`) while preserving `as const` literal types (with shell theme names in **`src/ui/theme.ts`**).

---

## 1. Non-Negotiable Labeling Rules

1. **Zero Hardcoded UI Strings in JSX**: Components in `src/components/` must never hardcode user-facing labels, headings, button captions, tooltips, placeholders, or `aria-label` strings. All copy is imported from the public facade `src/ui/labels.ts` (`APP_META`, `MACRO_BLOCK_META`, `getMacroBlockMeta`, or `UI_LABELS`).
2. **100% Platform- & Model-Agnostic Copy**: Never reference external video vendors, video model names, or platform dialects in UI labels, preset descriptions, tooltips, or empty states.
3. **Calm Editorial Tone**: Labels follow the *Physical Stationery & Blueprint Studio* voice—quiet, concise, utilitarian, and film-craft grounded (zero hype, zero marketing fluff, zero emoji).
4. **Glossary-Grounded Precision**: Structural labels distinguish **Phase 1 — Staging ($S_0$)** from **Phase 2 — Execution ($S_1 \to S_n$)** and never conflate Macro-Blocks, Macro-States, Sub-States, and inline `[BLOCK]` tags (see `docs/GLOSSARY.md`).

## 2. Auteur Script UI Vocabulary Contract

The editor displays canonical **Auteur Script (`v0.4.0`)** structural terms directly—never translating Macro-States into `"beats"` or Sub-States into `"steps"`, and never abbreviating Macro-State as `"MS"` (which collides with cinematography **Medium Shot**):

| Core / Glossary Term | Editor UI Representation | Where Used |
|---|---|---|
| **App Identity (`APP_META`)** | `ScriptFlow` (`version`: `1.1.0`, `specVersion`: `0.4.0`, `descriptor`: `Auteur Script Editor & Scene Blueprint`, `tagline`: `Draft the World. Direct Every Beat.`, `shortMark`: `S`) · fallback title `Untitled Scene` | Header slate, About modal & blank template |
| **Phase 1: STAGING ($S_0$)** | `Phase 1 — Staging` · `S0 · N Macro-Blocks` · `Add Macro-Block` · compact `MB` | Phase 1 section header, AI draft chip, & Debug stats |
| **Phase 2: EXECUTION ($S_1 \dots S_n$)** | `Phase 2 — Execution` · `S1 → SN` | Phase 2 section header |
| **Macro-State ($S_n$)** | Left-margin index `S1`, `S2`, … · count `N Macro-States` · actions `Add Macro-State` / `Delete S#` | Library rows/preview & sort (`Macro-States`), & Execution rows |
| **Sub-State ($s_i$)** | Quiet 1-based inline badges `S1.1`, `S1.2`, … · waterfall `Sub-State` (`S# lead Sub-State`, `S# Sub-State 2`, `Add Sub-State`, `Remove Sub-State`, `N Sub-States`) · `New Sub-State in S#` | Execution waterfall cards |

| **Script Supervisor Linter** | Header summary `N err · N warn` · Popover `Script Supervisor (N)` · `Repair: ` | Top slate bar & `DiagnosticDot` |

## 6. How to Safely Update or Add UI Copy

1. **Edit an existing label**: Update the entry directly in the owning module under `src/ui/labels/` (`meta.ts`, `editor.ts`, `library.ts`, `debug.ts`, or `ai.ts`)—or `THEME_OPTIONS` in `src/ui/theme.ts`. Changes propagate immediately across all components via the `src/ui/labels.ts` facade.
2. **Add a new UI control or section**:
   - Add the string or pluralization helper function (`(count: number) => ...`) under the matching namespace in its domain module (`src/ui/labels/editor.ts`, `library.ts`, `debug.ts`, or `ai.ts`), preserving `as const`.
   - Always import `UI_LABELS` from `src/ui/labels.ts` (never bypass the facade) and reference `UI_LABELS.<namespace>.<key>` inside JSX rather than typing inline literals.
3. **Add a new canonical Macro-Block kind**:
   - Add its `caption` and semantic `badgeClass` to `MACRO_BLOCK_META` in `src/ui/labels/meta.ts` (ensuring the badge CSS class defines `--phase-*` tokens for all 4 themes in `src/index.css`).
   - Update Section 3 of this document to keep the reference table in sync.
