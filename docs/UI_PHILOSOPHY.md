# UI Philosophy — ScriptFlow (`v1.0.0`, Auteur Script Editor & Scene Blueprint)

**ScriptFlow** (`v1.0.0`) blends **Obsidian Live Preview** with **Notion's calm single-page document flow**, rendered through the **Physical Stationery & Blueprint Studio** visual design system.

---

## 1. Two-Column Live Workspace, Source Mode & Read-Only Graph View

- **Two-Column Live Mode (`lg:` split, User-Adjustable)**: On desktop and landscape tablets (`lg:`), Live Mode splits cleanly into an asymmetric `40/60` pair of independently scrollable columns separated by a `1px` structural hairline—**Phase 1: Staging** on the left (`40%`) and **Phase 2: Execution** on the right (`60%`), each with a slim sticky header bar (`h-10`) so cast bindings (`@ref`), lookbook tokens, and coordinate fences stay visible while giving Execution Macro-States generous horizontal measure (`S1` → `S{N}`). Dragging the vertical divider (`25%`–`60%`, invisible at rest on mouse and widening to a `24px` touch target with a subtle resting grip on `pointer: coarse` screens, using primary `pointerId` capture and `--live-staging-split` with zero re-renders during drag, persisted in `localStorage`) adjusts the column split on demand; double-clicking / double-tapping the divider or clicking **Reset** in **Settings → Column layout** restores the default `40/60` split. On smaller viewports (`< lg`), both phases stack smoothly in a single vertical flow.
- **Single-Document Source Mode**: Switching to `Source` collapses into a single centered canonical plain-text document (`~820px` reading measure) in compact `JetBrains Mono` for raw editing and inspection, paired with three quiet header tools beside the line/char counter (zero new global keyboard shortcuts; mutually exclusive collapsible inline trays above the editor card): **`Find`** (Find & Replace with Case-sensitive `Aa`, Whole Word `W`, JavaScript Regex `.*` supporting `$1`/`$2`/`$&` backreferences and inline syntax-error feedback, Scope `All | Staging | Execution`, live zero-width-shift overlay match highlighting + smooth scroll-to-active-match inside `LiveHighlightedEditor`, local `Enter`/`Shift+Enter` match stepping and `Esc` dismiss, Find-only in read-only examples, and single-checkpoint `Cmd/Ctrl+Z` Undo), **`Rename`** (Safe Symbol Rename across Characters/speakers, `@ref` references, `[AESTHETIC]` Lookbook Tokens, and numbered `[CAM ##]` slots with live occurrence preview highlighting, boundary-safe replacement, format validation, collision-blocking guards, and single-checkpoint Undo; hidden in read-only examples), and **`Format`** (non-destructive whitespace cleanup, also accessible from `File ▾ → Format Script`). Dropping a `.txt`, `.md`, `.markdown`, or `.json` (`AuteurEnvelope`, `AuteurScriptIR`, `AuteurScriptDraft`, or single/multi-script `auteur-script-library-backup`, picking the first script) file directly onto the editable Source editor card immediately replaces the raw text in place as a single undoable checkpoint—staying in Source Mode, preserving the current Scene Title, and remaining disabled on read-only bundled examples. All inputs inside Source trays set `data-native-undo="true"`.
- **Read-Only Scene Blueprint Graph View (`Graph`, lazy-loaded via `@xyflow/react`)**: Accessed exclusively from the top bar **`[ Live | Graph | Source ]`** switcher (tablets & desktops `>= 640px`; mobile `< 640px` reverts automatically to read-only Live Mode), Graph View provides a strictly read-only, locked-card (`draggable: false`, `selectable: false`), pan-anywhere scene blueprint of the current script with zero initial bundle overhead until opened (isolated in its own stacking context so top-bar `Settings` / `File` / `Copy` popovers always float above Graph overlays). Desktop keeps scroll-wheel zoom + click-drag pan, while touchscreens support 1-finger pan anywhere over cards, 2-finger pinch-zoom (`zoomOnDoubleClick={false}`, `paneDragThreshold={4}`, `touch-none overscroll-none`), mouse-only hover tracing (`pointerType === 'mouse'`) to avoid sticky hover, preserved drag-to-select text inside `Source` (`</>`) boxes (`nopan select-text`), `@media (pointer: coarse)` touch-sized HUD/card controls, and tablet-friendly defaults (`MiniMap` off by default below `1024px`). It uses an orientation-aware **3-tier stratified layout**: **`L → R`** (default horizontal overview: **Tier 1 Staging (`MB#`)** ↓ **Tier 2 Inferred Objects** ↓ **Tier 3 Execution (`S1` → `SN`)**) starts **fully folded** (both Macro-States and `[AESTHETIC]` Lookbook cards), while **`T ↓ B`** (90° 3-column vertical deep-dive) starts **unfolded** (all Macro-States and `[AESTHETIC]` Lookbook swatch mini-cards expanded with generous card spacing and ruler-straight horizontal Sub-State chains, with **`Source`** branches collapsed in both). Strict tier boundaries prevent direct Tier 1 → Tier 3 wires, routing **cascading state-flow threads** as **rounded orthogonal dashed Blueprint pipes** (`Declaring Block / Lookbook Key → Inferred Object → first active Macro-State → first split Sub-State → prev → next` chronological cascade, plus Tier 2 ↔ Tier 1 downstream Staging references), keeping off-thread owning Macro-State headers slightly dimmed (`isSecondaryTraced`) with visible structural ownership chains while active thread nodes glow cleanly. Consecutive `HOLD` runs wrap in dashed **Shot Chambers**, while camera recalls stay quiet on the spine (`RECALL CAM ##`) at rest and expand on demand into stepped cascading subway lanes when focusing a `CAM ##` badge, isolating **`CAM`**, or toggling **`Threads`**. Perimeter chrome follows a clean **3-Anchor Canvas HUD** freeing the top-right and bottom-left corners at rest: a passive **Top-Left Scene Topology & counts pill** (`GraphHud`), a **Bottom-Center Two-Tier Studio Dock** (`SubStateIsolatorDock`) stacking a slim **upper View pill** (`[ L → R | T ↓ B ]` + compact **icon-only** `Split`/`Fold`, `Source`, `Threads`, and an always-visible icon-only **`Reset`** button softly emphasized when `isGraphViewModified()` is true) above a wider **lower Filter base pill** (`All` + borderless dot-badged dimension chips `● CAM`, `● BLOCK`, `● ACT`, etc., lighting up with full semantic fill when active, with **`Ghost | Compact`** floating in a detached right satellite on desktop `>= 1024px` and docking centered above the Filter pill on tablet widths `< 1024px` so chips stay stationary at `0px` shift without colliding with the zoom bar), and a **Bottom-Right Zoom / Fit / Map / `?` Help bar** (`ZoomControlsBar`) whose `?` trigger toggles a click/Escape-dismissible interaction tips popover (`attachCaptureOutsideDismiss`). A **gliding SVG pulse dot** animates `from → to` selectively on **isolated tag threads** and **single-object traces** (while unfiltered **`Threads`** stays static on lane-separated pipes, honoring `prefers-reduced-motion`); clicking any Inferred Object or inline entity opens the calm read-only **Object Inspector** anchored cleanly in the open top-right corner (`top-3 right-3`) with live Call Site `fitView` focus; Script Supervisor linter diagnostics are hidden in Graph View for clean presentations; and **`Reset`** restores the current orientation's default folded/unfolded posture, hides source viewers, clears threads and dimension filters, and refits the canvas.
- **Whisper-Quiet Top Bar (`h-12`)**: Holds only essential workflow controls—a theme-adaptive horizontal **`ScriptFlow`** brand logo (`SCRIPTFLOW - BLACK.png` / `SCRIPTFLOW - WHITE.png`, pixel-aligned to `h-7 md:h-8 lg:h-9` alongside `30px` pill controls) anchored on the far left beside the calm StageFlow-style **`File ▾`** menu (slim inline micro-headers, rounded hover rows with colorful semantic icons and mono format tags, organized into `Script & History` [`New Blank Script`, `Duplicate Script`, `Import / Restore...` opening the lazy-loaded whole-modal drag-and-drop `ScriptImportModal`, `Format Script`, `Version History...`, `AI Chat History...`], `Export & Library` [`Download ▸` flyout for `Canonical .txt`, `Tagless .txt`, `JSON Envelope`, plus `Backup All Scripts`, `Browse Library...`], and `Tools & Settings` [`JSON IR Inspector...`, `Settings`]), a clickable **Scene Title** pill button (`Libre Baskerville`, paired with a compact `<GitFork /> N` family count badge when part of a multi-branch family or a subtle `Example` pill on read-only bundled examples) that opens the unified **Project, Lineage & Version History** hub (`VersionHistoryModal`), quiet diagnostic jump pill, `[ Live | Graph | Source ]` segmented switcher with semantic tab icons (`emerald` Live, `sky` Graph, `amber` Source), quiet **Undo / Redo** button pair (`⌘Z / Ctrl+Z`, `⇧⌘Z / Ctrl+Y` — seamlessly swapped for a refined stationery **`Fork to Edit`** pill button on read-only examples), icon-only **`Library`** button (`amber` Book), icon-only **`Settings`** gear button (`indigo` animated gear; ## 3. Live Mode Interaction Patterns

### Phase 1 — Collapsible Staging Cards & Pluggable Block Editors
- Each Staging Macro-Block (`[INTENT]`, `[LOGIC]`, `[AESTHETIC]`, `[OPENING]`, `[CONTINUITY PROTOCOL]`, custom blocks) renders as a single-elevation stationery card with a semantic phase badge.
- Collapsing a Macro-Block keeps the header clean (`[BLOCK]` badge + caption + quiet right-aligned metadata such as `@refs`, `tokens`, `X keys` for `[AESTHETIC]`, or `X lines`) and shows a muted 2-line plain-text preview (`line-clamp-2`) underneath; clicking either the header or preview expands the block.
- **Pluggable Block Editor Registry (`stagingBlockRegistry.ts`)**: `[AESTHETIC]` renders through a structured 2-column live editor (`AestheticBlockEditor`) with bold keys in Column 1 and hanging-indent live-highlighted values in Column 2. All other Staging Macro-Blocks stay live-formatted via `LiveHighlightedEditor`, and future structured blocks plug directly into the registry.
- **Surgical Staging Management & Drag Reordering (`StagingPane`)**: Hover before or between Staging cards for an inline `+` insert seam (or use the bottom `+ Add Macro-Block` picker for canonical and custom headers), drag the hover-revealed `⋮⋮` header handle (or press `Space` + `↑`/`↓` on the focused handle) via the shared `SortableList` engine for animated live-sliding reordering with a compact floating header preview (preserving per-card collapsed state across reorders, inserts, and deletes), and hover any Staging card header to delete it via the decoupled `ConfirmDialog`.

### Phase 2 — Always-Formatted Option A Waterfall Stack
- **Lead Sub-State, Inline `S#.#` Badges & Waterfall Rail**: Sub-State 1 (`S1.1`) leads the Macro-State card and Sub-States $2 \dots k$ (`S1.2`, `S1.3`, …) indent under a `2px` vertical hairline rail prefixed with `↳`. Every committed Sub-State displays a quiet, pure-visual monospace `S#.#` badge aligned 1-to-1 with canonical JSON IR & AI addressing (toggleable with zero React re-renders via **Settings → Sub-State IDs**, `data-substate-ids`, On by default; uncommitted pending rows show only `↳`). Clicking any Sub-State places the caret directly inside that formatted Sub-State without collapsing the waterfall.
- **Live Chaining, Merging & Keyboard Reordering (`src/ui/subStateKeyboard.ts`)**: Pure keyboard and draft transition reducers drive every waterfall gesture cleanly:
  - Typing `-> ` (or `→ `) or pressing `Enter` inside any Sub-State immediately forks into the next indented `↳` Sub-State (or opens a pending `↳` row below) and moves focus there.
  - Pressing `Backspace` at column `0` of an indented `↳` Sub-State deletes an empty Sub-State or merges it cleanly back into the previous Sub-State.
  - `ArrowUp` at column `0` and `ArrowDown` at the end of a Sub-State navigate smoothly across waterfall Sub-States, while `Escape` blurs focus cleanly (including in read-only mode).
  - Pressing `Alt+↑` / `Alt+↓` (macOS `Option+↑` / `Option+↓`) inside any focused Sub-State moves that Sub-State up or down freely across `0..k` within its Macro-State as an undoable checkpoint while preserving focus and caret/selection position—keeping zero drag-handle clutter inside the waterfall rail (hinted quietly as `· Alt+↑↓ to move` in the focused-only footer whenever a Macro-State has 2+ Sub-States).
- **Camera Continuity Rail vs. Cut Hairline**:
  - Consecutive Macro-States sharing the same numbered camera slot (`[CAM 01]` $\to$ `[CAM 01]`) link via a continuous vertical rail in the left margin with tight vertical rhythm.
  - Camera slot switches (`[CAM 01]` $\to$ `[CAM 02]`), recalls (`[CAM 01] ->`), or unnumbered `[CAM]` montage lines render a crisp dotted `cut` (or `cut · recall`) hairline between Macro-States with expanded breathing room.
- **Collapsible Macro-States (`ExecutionPane` / `ExecutionBeatRow`)**: Each Macro-State card carries a quiet per-row collapse chevron alongside Sub-State 1, and the sticky Execution header mirrors Staging with a bulk `Collapse all` / `Expand all` toggle. Collapsing a Macro-State hides its indented `↳` waterfall and shows a muted 2-line clamped chained preview (`line-clamp-2`) with right-aligned `N Sub-States` metadata while preserving the `S#` index, camera continuity rail / `cut` dividers, drag-to-reorder, hover delete, and right-margin diagnostics; clicking either the chevron or collapsed card expands it. Collapse state tracks indices cleanly across drag-reorders, insertions (new Macro-States start expanded), and confirmed deletions.
- **Surgical Macro-State Management**: Hover between Macro-States for a surgical `+` insert button, focus any Macro-State card for `+ Add Sub-State` (or hover the card header for quick `+` and confirmed `Trash2` deletion via `ConfirmDialog`), or drag the hover-revealed `⋮⋮` handle in the left margin (with keyboard `Space` + `↑`/`↓` support) for animated live-sliding Macro-State reordering with a compact floating Macro-State preview.

### Toggleable Clause Underlines (Off by Default)
- Enabled via **Settings → Clause underlines** (`data-clause-guides="true"` on `<html>`): comma-separated phrases receive a faint monochrome dotted underline and sentence/semicolon clauses receive a subtle solid hairline underline, while punctuation characters stay un-underlined as crisp visual breaks. Decimals (`2.39:1`), ellipses (`...`), abbreviations (`O.S.`, `Mr.`), and spoken `{dialogue}` are intentionally skipped.

### Quiet Hover-to-Diff AI Patch & Quick Scan Indicators (Actionable, Zero Layout Shift)
- **Affected cards & rows (`AiPatchIndicator`)**: Whenever one or more unapplied, undismissed, non-stale AI patches (or Audit Review embedded fixes) are staged in the open AI sidebar, affected Staging Macro-Block cards (`MB#`) and Execution Macro-State rows (`S#`) display a subtle inset accent border tint (sky for modify/reorder, red for delete) and a quiet circular `AiPatchIndicator` dot stacked cleanly in the existing `24px` right margin alongside `DiagnosticDot`—preserving normal live editing and zero horizontal shift.
- **Hover to peek, click to pin, act inline**: Hovering the indicator opens a compact popover showing the exact word-level before/after diff for that Macro-Block or Macro-State (with unchanged context lines compacted on longer Staging blocks); clicking pins the popover open (`Esc` or clicking outside closes). Inline **`Apply` / `Apply Fix` / `Fork & Apply`** (and **`Dismiss`** for Refine patches) buttons inside the popover stay 2-way synced with AI sidebar receipts, trigger automatic pre-apply Version History snapshots, and commit as single-checkpoint `Cmd/Ctrl+Z` edits.
- **Insertion seams (`AiPatchInsertionSeam`)**: Proposed `insert_macro_block` and `insert_macro_state` operations render a thin dashed emerald pill (`+ AI Insert ...`) at the exact insertion slot between cards/rows, revealing the proposed content and inline Apply/Dismiss controls on hover/pin. Indicators disappear immediately once a patch is applied, dismissed, becomes stale after a manual edit, or when the AI sidebar closes.
- **Quick Scan suspect `S#` indicators (`AiQuickScanIndicator`)**: When a fresh Decisions API Quick Scan flags one or more atomic semantic rules on an Execution Macro-State (`S#`)—including per-Sub-State (`S#.#`) rules—a quiet circular `ScanSearch` indicator appears in the `24px` right margin (hidden whenever a verified `AiPatchIndicator` is already active on that row). Hovering or clicking opens a compact popover listing the exact tripped rule labels, `S#.#` badges where applicable, calibrated percentages (or `Lint` badge for deterministic hits), and a 1-click **`Audit S#`** action; indicators clear automatically on manual edits (stale `snapshotHash`), dismissal, a superseding Deep Audit, or closing the AI sidebar.
