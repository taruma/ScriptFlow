# UI Philosophy — Auteur Script Editor

The Auteur Script Editor blends **Obsidian Live Preview** with **Notion's calm single-page document flow**, rendered through the **Physical Stationery & Blueprint Studio** visual design system.

---

## 1. Two-Column Live Workspace, Source Mode & Read-Only Graph View

- **Two-Column Live Mode (`lg:` split, User-Adjustable)**: On desktop and landscape tablets (`lg:`), Live Mode splits cleanly into an asymmetric `40/60` pair of independently scrollable columns separated by a `1px` structural hairline—**Phase 1: Staging** on the left (`40%`) and **Phase 2: Execution** on the right (`60%`), each with a slim sticky header bar (`h-10`) so cast bindings (`@ref`), lookbook tokens, and coordinate fences stay visible while giving Execution Macro-States generous horizontal measure (`S1` → `S{N}`). Dragging the vertical divider (`25%`–`60%`, invisible at rest on mouse and widening to a `24px` touch target with a subtle resting grip on `pointer: coarse` screens, using primary `pointerId` capture and `--live-staging-split` with zero re-renders during drag, persisted in `localStorage`) adjusts the column split on demand; double-clicking / double-tapping the divider or clicking **Reset** in **Settings → Column layout** restores the default `40/60` split. On smaller viewports (`< lg`), both phases stack smoothly in a single vertical flow.
- **Single-Document Source Mode**: Switching to `Source` collapses into a single centered canonical plain-text document (`~820px` reading measure) in compact `JetBrains Mono` for raw editing and inspection, with a quiet **`Format`** button beside the line/char counter for non-destructive whitespace cleanup (also accessible from `File ▾ → Format Script`).
- **Read-Only Spatial Graph View (`Graph`, lazy-loaded via `@xyflow/react`)**: Accessed exclusively from the top bar **`[ Live | Graph | Source ]`** switcher (desktop `>= 640px`), Graph View provides a read- and view-only spatial blueprint of the current script with zero initial bundle overhead until opened. It uses a **3-tier stratified layout** (`L → R` default horizontal bands: **Tier 1 Staging (`MB#`)** ↓ **Tier 2 Inferred Objects** ↓ **Tier 3 Execution (`S1` → `SN`)**; `T ↓ B` 90° transpose into 3 parallel vertical columns) where **`[AESTHETIC]`** opens by default into distinct Lookbook Key–Value swatch mini-cards (`AestheticItemNode`, with **`Keys`/`Fold`** and **`Source`** branch controls and zero-overlap framing across both orientations). Strict tier boundaries prevent direct Tier 1 → Tier 3 wires, routing **cascading state-flow threads** as **rounded orthogonal dashed Blueprint pipes** (`Declaring Block / Lookbook Key → Inferred Object → first active Macro-State → first split Sub-State → prev → next` chronological cascade, plus Tier 2 ↔ Tier 1 downstream Staging references), reserving curved arcs strictly for camera **`RECALL`** links alongside dashed **Shot Chambers**. All Execution Macro-States open **folded (compact)** with **`Source`** collapsed by default and split on demand into sculpted Sub-State cards (Screenplay Dialogue micro-blocks, Foley waveforms, Score bars, Framed Serif Title Cards, and clickable Camera slates). A floating **Sub-State Isolator Dock** dynamically shows only dimensions detected in the current scene (including `Other` for undetected/plain Sub-States) in **`Ghost`** or **`Compact`** mode; a **gliding SVG pulse dot** animates `from → to` selectively on **isolated tag threads** and **single-object traces** (while unfiltered **`Show Threads`** stays static on lane-separated dashed pipes, honoring `prefers-reduced-motion`); clicking any Inferred Object or inline entity opens a calm read-only **Object Inspector** with live Call Site `fitView` focus; Script Supervisor linter diagnostics are hidden in Graph View for clean presentations; and **`Reset`** restores dragged positions, `[AESTHETIC]` open posture, folded Macro-States, hidden source viewers, and refits the canvas.
- **Whisper-Quiet Top Bar (`h-12`)**: Holds only essential workflow controls—a crisp **`ScriptFlow`** app title anchored on the far left beside the calm **`File ▾`** menu (`New Blank Script`, `Duplicate Script`, `Import File (.txt / .json)...`, `Format Script`, `Version History...`, `Download Canonical .txt`, `Download Tagless .txt`, `Download JSON Envelope`, `Backup All Scripts (.json)`, `Restore Backup (.json)...`, `Browse Library...`, `JSON IR Inspector...`, and `Settings`), editable scene title (`Libre Baskerville`, paired with a subtle `Example` pill when viewing a read-only bundled example), quiet diagnostic jump pill, `[ Live | Graph | Source ]` segmented switcher, quiet **Undo / Redo** button pair (`⌘Z / Ctrl+Z`, `⇧⌘Z / Ctrl+Y` — seamlessly swapped for a refined stationery **`Fork to Edit`** pill button on read-only examples), icon-only **`Library`** button, icon-only **`Settings`** gear button (also openable from `File ▾ → Settings`, housing Text Size `13px`–`16px` stepper, toggleable monochrome **Clause Underlines**, toggleable **Sub-State IDs** (`S1.1`, `S1.2` Execution waterfall badges, On by default), **Column layout → Reset** to restore the default `40/60` Live Mode split, 2×2 4-mode **Theme** grid, a compact **Supervisor rules** drill-down panel with per-rule `Off` / `Warn` / `Error` toggles and `Reset defaults`, and a **JSON IR Inspector** launch row), quiet **`AI`** toggle button immediately to the left of Copy (lazy-loaded right-side AI Canvas Sidebar), and a split **`Copy | ▾`** button (1-click main button copies Canonical Plain Text; chevron opens `Copy Plain Text`, `Copy Tagless`, and `Copy JSON Envelope`).
- **Narrow-Viewport Read-Only Mode (`< 640px` / `sm`, `useNarrowViewport`)**: Below `640px`, the app shifts cleanly into a dedicated read-only script reader and 1-tap copy studio. `TopSlateBar` replaces `ScriptFlow` with the compact **`S`** monogram placeholder (`APP_META.shortMark`), hides `File ▾`, diagnostics, `[ Live | Graph | Source ]`, Undo/Redo, `Fork to Edit`, and `AI`, renders the Scene Title as a non-editable truncated label, and keeps only **Library**, **Settings** (display/themes only, hiding JSON IR Inspector), and a **single icon-only 1-tap Copy button** (Canonical Plain Text only). Inside the stacked Live workspace, Phase 1 Staging and Phase 2 Execution render slim, full-width compact section headers (`h-8`, showing only the **Staging** / **Execution** title and **`Collapse all` / `Expand all`** toggle while hiding phase kickers, `[EXECUTION]` badges, and counts) and collapse the `24px` right-margin diagnostic/AI indicator column (hiding `DiagnosticDot`s and tightening Execution's left `S#` track to `28px`) so cards sit flush with symmetric horizontal margins. The workspace forces **Live Mode** (preserving the desktop view mode if resized back up), auto-closes desktop-only drawers/modals (`AI Sidebar`, `Version History`, `JSON IR Inspector`), locks Live editing/DnD/paste/undo with an accurate narrow read-only footer hint, and opens `ScriptLibraryModal` in **browse-and-open-only mode** (hiding `New Blank`, `Import`, `Clear Library`, bulk `Select`, inline `Rename`, `Pin`, `Folder`/`Tags` editing, `Duplicate`, `Delete`, and `Fork to Edit`).
- **Two-Pane Version History Modal (`VersionHistoryModal`, lazy-loaded via `File ▾ → Version History...`)**: Opens a calm two-pane modal (`aria-modal="true"`) dedicated to pre-AI checkpoints (`AI Draft`, `AI Patch`, `Audit Fix`), `Pre-Restore` safety snapshots, and optional manual **Milestones**—keeping zero clutter on the main toolbar and zero per-keystroke noise. The left pane hosts an inline `Save` milestone input (`data-native-undo="true"`) and chronological snapshot list (with trigger badges, pin indicators, relative timestamps, and Macro-State counts); the right pane provides `[ Diff vs. Current | Full Script ]` inspection, Pin/Unpin (protecting auto-checkpoints from the 30-item FIFO cap), confirmed Delete / Clear History (`ConfirmDialog`), **Fork as New Script**, and 1-click **Restore** (auto-saving a `Pre-Restore` checkpoint first and committing as an undoable `Cmd/Ctrl+Z` edit).
- **Right-Side AI Canvas Sidebar, Bottom Focus/Scope/Model Dock, Dedicated Brief Modal, Context Inspector, AI Settings & Opt-In Trace Inspector (`AiAssistantSidebar`, `AiBriefModal`, `AiContextInspectorModal`, `AiSettingsModal`, `AiTraceModal`, lazy-loaded)**: Zero overhead when closed—Live (`40/60`) and Source modes remain completely unchanged. Clicking **`AI`** docks a resizable right-side canvas (`340px`–`580px` on desktop, responsive drawer on narrow viewports) inside the viewport-locked desktop shell (`lg:h-dvh lg:overflow-hidden`) so Staging, Execution, Source, and the AI message stream each scroll independently without whole-page scrolling, keeping the minimal sidebar header and unified bottom composer dock permanently anchored. The slim top header holds only the **`AI Assistant`** title alongside a quiet **`Context`** button (with active skill count and customization/update indicator dot opening the lazy-loaded **`AiContextInspectorModal`**, `aria-modal="true"`, 4 tabs: **Live Prompt Preview**, **Foundational Craft**, **Skills & Extensions**, and **Quick Scan Rules** via `QuickScanRulesTabPanel`, with confirmed custom skill/rule CRUD via `ConfirmDialog` plus unified **`Export JSON`** and selective **`Import JSON`** via `AgentContextImportDialog`), **`New Chat`**, and **`Close`**—maximizing vertical room for the message stream. At the bottom sits a **resizable composer dock**: a subtle top drag handle (`row-resize`, double-click to reset) plus smooth auto-grow (`56px`–`180px`, manually draggable up to `360px` / `48%` of sidebar height) lets authors write longer briefs comfortably. Directly below the prompt box sit the 4-tab **`Auto` | `Draft` | `Refine` | `Audit`** Focus bar, contextual Target Scope selector (`Whole Script`, `MB#`, `S#`) + quiet **`Quick Scan`** & **`Audit All`** pills in `Auto` (or **`Quick Scan`** alongside the 6 deep-audit lens pills `All Lenses` and `Lens 1`–`Lens 5` in `Audit`), and a bottom utility row pairing the **`Brief`** modal trigger and opt-in **`Ask First`** clarifying-question toggle pill (shown outside `Audit`, auto-resetting after send so `ask_question` is never invoked unprompted) on the left with a quiet cumulative **session estimated cost** pill (when `Show estimated cost` is enabled and turns have completed, with a portal hover token/USD breakdown tooltip) immediately to the left of the clickable **`Model · Level`** settings chip on the right (opening the compact **`AiSettingsModal`**, `aria-modal="true"`, BYOK API key with show/hide, `Clear Key`, inline `Session only` switch, 3-column Gemini 4 `Hydrogen` → `Neon` → `Carbon` selector plus a slim `3.5 Flash-Lite` budget row underneath with live per-1M rates, compact segmented Reasoning Level bar, **Quick Scan Sensitivity** segmented bar (`Strict` / `Balanced` / `Lenient` for `gemini-decision-1`), unified 3-row display toggle card for `Show reasoning summary`, `Show estimated cost`, and opt-in `Show Debug Trace`, plus a **`Reset to defaults`** footer button that restores preferences without clearing the API key). Clicking **`Brief`** opens the dedicated lazy-loaded **`AiBriefModal`** (`aria-modal="true"`, full breathing room never clipped by the prompt box) with an explicit **`Include in AI context`** switch (`Brief · Off` when paused), a visual reference card grid supporting drag-and-drop local images (`1600px` / `85%` in-browser compression) and inline text files, browser-direct **Gemini Files API** uploads & 48h cloud file browsing (for video, audio, PDFs, and full-fidelity originals up to 2 GB), public **YouTube URL** attachments with live thumbnails and `Static`/`Agentic` video toggles, manual `@handle` rows (all passively triggering matching skills across all modes and transmitting media once per `previous_interaction_id` chain), `Format & Specs`, `Subtext & Additional Instructions`, and `Clear`—injecting active Brief context cleanly into `system_instruction` across all modes while sending composer messages verbatim (all inputs carry `data-native-undo="true"`). Every assistant turn renders Markdown safely (`MarkdownContent`), follows live streaming via sticky-bottom auto-scroll (pausing cleanly when scrolled up, with a quiet floating **`↓ Latest`** pill), separates the bounded collapsible **Thinking** summary from a scannable **Skills & Tools** pill strip (`Auto`, `Pinned`, `Loaded` skills + tool call status pills with portal hover tooltips), renders Layer 2.5 **`QuickScanCard`** scorecards (per-lens checkboxes, expandable findings, suspect `S#` jumps, and **`Deep Audit Selected (N)`** / **`Run Full Deep Audit`** escalation), and stages **never-auto-applied** review cards (`PatchSuggestion`, `DraftSuggestion`, `AuditReviewSuggestion`, and opt-in multi-select + inline-comment `QuestionSuggestion` cards that submit structured answers into a follow-up-capable turn and collapse into quiet single-line `Answered` receipts—with multi-issue Audit cards starting collapsed under `Show N issues ▸` so the assistant's text reply stays readable first, and applied/dismissed Patch & Draft cards auto-collapsing into quiet single-line receipts) with expandable line diffs, stale-snapshot protection, clickable editor jump links, single-checkpoint `Undo` on user scripts, seamless one-click **`Fork & Apply`** on read-only bundled examples, and 2-way synced **`Apply` / `Dismiss`** actions directly inside Live Mode's hover-to-diff popovers. When **Show Debug Trace** is enabled, completed, Quick Scan, and failed/stopped turns surface a quiet **`Inspect`** button opening **`AiTraceModal`** (`aria-modal="true"`, 4-theme parity) to review sanitized Interactions API requests or Decisions API Quick Scan question/answer matrices, `Focus` and active/loaded skill chips, round-by-round tool calls/self-repair hints, token usage, estimated cost, interaction ID chains, and error details with one-click **`Copy Trace JSON`**.
- **Editorial Two-Pane Script Library (`ScriptLibraryModal`, `LibraryPreviewPane`)**: Opens instantaneously as a calm, wide two-pane modal (`aria-modal="true"`, zero full-viewport backdrop blur) separated by a `1px` structural hairline. The modal header hosts (when saved scripts exist) a quiet **`Clear Library`** action positioned safely to the left of **`New Blank`** and **`Import`** (away from the `×` close button) whose `ConfirmDialog` includes an inline **`Backup All Scripts (.json)`** button so users can download a full backup without leaving the confirmation dialog before clearing saved scripts (leaving bundled examples, editor settings, and AI config untouched). The **left pane** provides full-text search across titles, folders, tags, and script bodies (with inline match excerpts), full-width segmented filter tabs (`All` / `My Scripts` / `Examples`), a custom theme-aware sort popover (`Recent` / `A–Z` / `Macro-States` with pinned scripts floating first), a quiet folder/tag facet strip (only revealed when folders or tags exist), paginated rows (`50` per page, fast lightweight Macro-State counts computed strictly on visible rows, and a `2px` left accent bar + tinted fill on the selected row), keyboard navigation (`↑` / `↓` / `Enter` / `Esc`, closing the sort menu first), and an opt-in **Select** mode for bulk JSON export or confirmed bulk deletion via `ConfirmDialog`. The **right pane** displays a live read-only **Preview / Source** inspector for the selected script (Phase 1 Staging Macro-Block excerpts + Phase 2 Execution Macro-State preview, automatically resetting scroll to top on script switch), inline **Rename**, **Pin**, **Folder** & **Tags** organization, and quiet footer actions (`Duplicate`, `Export .txt`, `Delete`, or `Fork to Edit` on read-only examples).
- **Read-Only Bundled Examples + Explicit Fork**: Bundled reference scripts open strictly **read-only** without polluting the user's IndexedDB library and without adding any extra banner strip, preserving `LiveDocument`'s full `calc(100dvh - 3rem)` desktop canvas height. `TopSlateBar` displays a subtle `Example` pill beside the read-only Scene Title and swaps Undo/Redo for a calm, hover-elevated **`Fork to Edit`** stationery pill; all mutating controls (Live/Source editing, title editing, Macro-Block/Macro-State CRUD/reorder, Undo/Redo, Debug IR commits, and Paste-and-Hydrate) remain locked while reading, collapsing/expanding, Live/Source switching, Copy, Export, and JSON IR inspection work seamlessly.
- **Document-Level Undo / Redo**: Every edit across Live Mode and Source Mode commits to a pure plain-text history stack (`src/core/history.ts`)—rapid typing bursts coalesce automatically while structural edits (splits, merges, inserts, deletes, drag-reorders, paste hydration, debug commits) create crisp checkpoints, and script switches/forks/imports reset history cleanly. Actively focused Live Mode drafts resync immediately on Undo/Redo (`historyRevision`), while non-document inputs (`data-native-undo="true"`) preserve native browser undo and open modals (`aria-modal="true"`) are never intercepted.
- **Resilient Crash Recovery (`ErrorBoundary`)**: A minimal, theme-aware top-level Error Boundary wraps the workspace so any unexpected render error presents a calm recovery card with **Reload Editor** and **Copy Saved Script** straight from the active `localStorage` mirror.
- **Zero Chrome Bloat**: No noisy telemetry widgets, zero idle vertical footer padding inside resting Macro-State cards, and zero layout shift when diagnostics appear in the right margin of either column.
- **Headless Programmatic Engine**: All AI-facing JSON IR serialization, transactional patching, and Script Supervisor dimension slicing live strictly inside `src/core/` (`docs/JSON_IR_SPEC.md`)—keeping the human editor purely focused on canonical plain text and live formatting.

## 3. Live Mode Interaction Patterns

### Phase 1 — Collapsible Staging Cards & Pluggable Block Editors
- Each Staging Macro-Block (`[INTENT]`, `[LOGIC]`, `[AESTHETIC]`, `[OPENING]`, `[CONTINUITY PROTOCOL]`, custom blocks) renders as a single-elevation stationery card with a semantic phase badge.
- Collapsing a Macro-Block keeps the header clean (`[BLOCK]` badge + caption + quiet right-aligned metadata such as `@refs`, `tokens`, `X keys` for `[AESTHETIC]`, or `X lines`) and shows a muted 2-line plain-text preview (`line-clamp-2`) underneath; clicking either the header or preview expands the block.
- **Pluggable Block Editor Registry (`stagingBlockRegistry.ts`)**: `[AESTHETIC]` renders through a structured 2-column live editor (`AestheticBlockEditor`) with bold keys in Column 1 and hanging-indent live-highlighted values in Column 2. All other Staging Macro-Blocks stay live-formatted via `LiveHighlightedEditor`, and future structured blocks plug directly into the registry.
- **Surgical Staging Management & Drag Reordering (`StagingPane`)**: Hover before or between Staging cards for an inline `+` insert seam (or use the bottom `+ Add Macro-Block` picker for canonical and custom headers), drag the hover-revealed `⋮⋮` header handle (or press `Space` + `↑`/`↓` on the focused handle) via the shared `SortableList` engine for animated live-sliding reordering with a compact floating header preview (preserving per-card collapsed state across reorders, inserts, and deletes), and hover any Staging card header to delete it via the decoupled `ConfirmDialog`.

### Phase 2 — Always-Formatted Option A Waterfall Stack
- **Lead Sub-State, Inline `S#.#` Badges & Waterfall Rail**: Sub-State 1 (`S1.1`) leads the Macro-State card and Sub-States $2 \dots k$ (`S1.2`, `S1.3`, …) indent under a `2px` vertical hairline rail prefixed with `↳`. Every committed Sub-State displays a quiet, pure-visual monospace `S#.#` badge aligned 1-to-1 with canonical JSON IR & AI addressing (toggleable with zero React re-renders via **Settings → Sub-State IDs**, `data-substate-ids`, On by default; uncommitted pending rows show only `↳`). Clicking any Sub-State places the caret directly inside that formatted Sub-State without collapsing the waterfall.
- **Live Chaining, Merging & Keyboard Reordering (`src/ui/subStateKeyboard.ts`)**: Pure keyboard and draft transition reducers drive every waterfall gesture cleanly:
  - Typing `-> ` (or `→ `) or pressing `Enter` inside any Sub-State immediately forks into the next indented `↳` Sub-State (or opens a pending `↳` row below) and moves focus there.
  - Pressing `Backspace` at column `0` of an indented `↳` Sub-State deletes an empty Sub-State or merges it cleanly back into the previous Sub-State.
  - `ArrowUp` at column `0` and `ArrowDown` at the end of a Sub-State navigate smoothly across waterfall Sub-States, while `Escape` blurs focus cleanly (including in read-only mode).
  - Pressing `Alt+↑` / `Alt+↓` (macOS `Option+↑` / `Option+↓`) inside any focused Sub-State moves that Sub-State up or down freely across `0..k` within its Macro-State as an undoable checkpoint while preserving focus and caret/selection position—keeping zero drag-handle clutter inside the waterfall rail (hinted quietly as `· Alt+↑↓ to move` in the focused-only footer whenever a Macro-State has 2+ Sub-States).
- **Camera Continuity Rail vs. Cut Hairline**:
  - Consecutive Macro-States sharing the same numbered camera slot (`[CAM 01]` $\to$ `[CAM 01]`) link via a continuous vertical rail in the left margin with tight vertical rhythm.
  - Camera slot switches (`[CAM 01]` $\to$ `[CAM 02]`), recalls (`[CAM 01] ->`), or unnumbered `[CAM]` montage lines render a crisp dotted `cut` (or `cut · recall`) hairline between Macro-States with expanded breathing room.
- **Collapsible Macro-States (`ExecutionPane` / `ExecutionBeatRow`)**: Each Macro-State card carries a quiet per-row collapse chevron alongside Sub-State 1, and the sticky Execution header mirrors Staging with a bulk `Collapse all` / `Expand all` toggle. Collapsing a Macro-State hides its indented `↳` waterfall and shows a muted 2-line clamped chained preview (`line-clamp-2`) with right-aligned `N Sub-States` metadata while preserving the `S#` index, camera continuity rail / `cut` dividers, drag-to-reorder, hover delete, and right-margin diagnostics; clicking either the chevron or collapsed card expands it. Collapse state tracks indices cleanly across drag-reorders, insertions (new Macro-States start expanded), and confirmed deletions.
- **Surgical Macro-State Management**: Hover between Macro-States for a surgical `+` insert button, focus any Macro-State card for `+ Add Sub-State` (or hover the card header for quick `+` and confirmed `Trash2` deletion via `ConfirmDialog`), or drag the hover-revealed `⋮⋮` handle in the left margin (with keyboard `Space` + `↑`/`↓` support) for animated live-sliding Macro-State reordering with a compact floating Macro-State preview.

### Toggleable Clause Underlines (Off by Default)
- Enabled via **Settings → Clause underlines** (`data-clause-guides="true"` on `<html>`): comma-separated phrases receive a faint monochrome dotted underline and sentence/semicolon clauses receive a subtle solid hairline underline, while punctuation characters stay un-underlined as crisp visual breaks. Decimals (`2.39:1`), ellipses (`...`), abbreviations (`O.S.`, `Mr.`), and spoken `{dialogue}` are intentionally skipped.

### Quiet Hover-to-Diff AI Patch & Quick Scan Indicators (Actionable, Zero Layout Shift)
- **Affected cards & rows (`AiPatchIndicator`)**: Whenever one or more unapplied, undismissed, non-stale AI patches (or Audit Review embedded fixes) are staged in the open AI sidebar, affected Staging Macro-Block cards (`MB#`) and Execution Macro-State rows (`S#`) display a subtle inset accent border tint (sky for modify/reorder, red for delete) and a quiet circular `AiPatchIndicator` dot stacked cleanly in the existing `24px` right margin alongside `DiagnosticDot`—preserving normal live editing and zero horizontal shift.
- **Hover to peek, click to pin, act inline**: Hovering the indicator opens a compact popover showing the exact word-level before/after diff for that Macro-Block or Macro-State (with unchanged context lines compacted on longer Staging blocks); clicking pins the popover open (`Esc` or clicking outside closes). Inline **`Apply` / `Apply Fix` / `Fork & Apply`** (and **`Dismiss`** for Refine patches) buttons inside the popover stay 2-way synced with AI sidebar receipts, trigger automatic pre-apply Version History snapshots, and commit as single-checkpoint `Cmd/Ctrl+Z` edits.
- **Insertion seams (`AiPatchInsertionSeam`)**: Proposed `insert_macro_block` and `insert_macro_state` operations render a thin dashed emerald pill (`+ AI Insert ...`) at the exact insertion slot between cards/rows, revealing the proposed content and inline Apply/Dismiss controls on hover/pin. Indicators disappear immediately once a patch is applied, dismissed, becomes stale after a manual edit, or when the AI sidebar closes.
- **Quick Scan suspect `S#` indicators (`AiQuickScanIndicator`)**: When a fresh Decisions API Quick Scan flags one or more atomic semantic rules on an Execution Macro-State (`S#`)—including per-Sub-State (`S#.#`) rules—a quiet circular `ScanSearch` indicator appears in the `24px` right margin (hidden whenever a verified `AiPatchIndicator` is already active on that row). Hovering or clicking opens a compact popover listing the exact tripped rule labels, `S#.#` badges where applicable, calibrated percentages (or `Lint` badge for deterministic hits), and a 1-click **`Audit S#`** action; indicators clear automatically on manual edits (stale `snapshotHash`), dismissal, a superseding Deep Audit, or closing the AI sidebar.
