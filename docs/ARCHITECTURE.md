# Architecture — ScriptFlow (`v1.0.0`, Auteur Script Editor & Scene Blueprint)

## 1. Plain-Text-as-Truth Data Flow

The editor treats the **canonical plain-text Auteur Script** as the single source of truth so Live Mode, Source Mode, clipboard exports, and `localStorage` persistence can never drift out of sync:

```text
                       ┌────────────────────────────────────┐
                       │  history.present: rawText (Truth)  │
                       │  (src/core/history.ts)             │
                       │  + useEditorSettings() (Display)   │
                       └─────────────────┬──────────────────┘
                                         │
              ┌──────────────────────────┼──────────────────────────┐
              ▼                          ▼                          ▼
   [ Pure Synchronous Pipeline ]   [ Pure UI Mutations ]   [ Programmatic JSON Engine ]
   1. parseAuteurScript(raw)       (src/core/serializer)   (src/core/ir, patch, slicer)
   2. extractMetadata(doc)         • insert/update/delete  • toAuteurIR / fromAuteurIR
   3. lintDocument(doc, meta, rules)  & reorder Staging     • toAuteurEnvelope / Draft
   4. tokenize* (highlighter)      • insert/update/delete  • applyAuteurPatch (tx+lint)
   5. parseAestheticRows             ExecutionBeat/Sub…    • sliceAuteurEnvelope (L1–L5)
                                   • reorderExecutionBeats • getAuteurJsonSchemas (Zod)
                                   • exportTagless
              │                          ▲                          ▲
              ▼                          │                          │
   [ Thin React + Tailwind UI (src/components/) ] ────────┘   [ AI / Automated Callers ]
   • ErrorBoundary -> App              • TopSlateBar -> FileMenuDropdown / SettingsPopover
   • LiveDocument -> StagingPane / ExecutionPane (SortableList + HoverInsertSeam)
   • StagingBlockCard -> Registry      • ExecutionBeatRow       • SourceEditor
   • LiveHighlightedEditor             • ScriptLibraryModal     • ConfirmDialog / DiagnosticDot
```

## 3. Pure Serializer Mutation Contracts

Every mutation function in `src/core/serializer.ts` obeys three invariants:
1. **Immutability**: Takes `(raw: string, ...args)` and returns a new canonical `string` without mutating inputs.
2. **Block Orthogonality**: Inserting (`insertStagingBlock`), editing (`updateStagingBlock`), deleting (`deleteStagingBlock`), or reordering (`reorderStagingBlocks`) a Staging Macro-Block preserves every other Staging Macro-Block and all Execution Macro-States untouched; editing, inserting, deleting, or reordering Execution Macro-States never alters Staging Macro-Blocks. `insertStagingBlock` also rejects reserved Execution headers (`EXECUTION`, `TIMELINE`, `BEATS`, `SHOTLIST`).
3. **Single-Line Macro-State Guarantee**: `updateExecutionBeat` and `insertExecutionBeat` normalize accidental internal newlines into single spaces so each Macro-State remains one clean line inside `[EXECUTION]`.

## 4. Global Document Guards (Paste-and-Hydrate & Undo/Redo)

`src/App.tsx` keeps the top-level shell declarative by delegating document-level clipboard and history listeners to `src/ui/useGlobalEditorShortcuts.ts` and memoized serializer mutations, clipboard exports, debug commits, and AI patch/draft applies to `src/ui/useDocumentMutations.ts`. Inside `useGlobalEditorShortcuts`, two document-level listeners coordinate frictionless script ingestion and history navigation without colliding with active inline inputs or open modals:

### Paste-and-Hydrate Guard
Uses `isMultiBlockAuteurScript()` from `src/core/parser.ts`:
- **Graph View (`viewMode === 'graph'`)**: Ignored so the read-only spatial canvas never mutates the underlying script on clipboard paste.
- **Modals & AI Sidebar (`isModalOpen` covering `isDebugOpen`, `isLibraryOpen`, `isVersionHistoryOpen`, `confirmRequest`; `[aria-modal="true"]`; or `[data-ai-sidebar="true"]`)**: Ignored so modal inputs (including `AiSettingsModal` API key entry, `AiBriefModal`, `AiContextInspectorModal`, and `VersionHistoryModal`) and AI chat composer pastes never trigger script hydration.
- **Read-only bundled examples**: Intercepts document-level pastes without mutating the read-only example and displays a gentle toast guiding the user to click **Fork to Edit** or create a **New Blank Script**.
- **Pasting outside any focused input/textarea (custom script)**: Immediately replaces `rawText` in place (as an undoable `'checkpoint'` history entry), parses the script, switches to Live Mode, and displays a subtle toast.
- **Pasting a multi-block Auteur Script (2+ canonical Macro-Block headers)** while inside a focused single Macro-Block or Macro-State editor in Live Mode: Blurs the active field and hydrates the entire script.
- **Pasting a normal inline snippet** while focused inside a Staging Macro-Block, Execution Macro-State, Scene Title, or Source Mode editor: Passes through natively without interception.

### Document-Level Undo / Redo Guard
Uses `matchHistoryShortcut()` (`src/ui/historyShortcuts.ts`) and `src/core/history.ts`:
- **Commit Modes & Lifecycle Reset**: Rapid typing commits with `mode: 'coalesce'` + a scoped `groupKey` (auto-checkpointing on bulk edits > 32 chars or pauses > 800ms); structural actions (splits, merges, inserts, deletes, reorders, paste-hydrate, AI suggestion applies, debug commits) commit with `mode: 'checkpoint'`. Switching scripts, forking an example, importing a script, or creating a blank script resets history cleanly via `createDocumentHistory()` (while **Fork & Apply** from the AI sidebar initializes the forked script's history from the example base with the AI edit committed as a single undoable checkpoint).
- **Read-Only, Graph View, Modal & Native-Input Isolation**: Skips shortcuts when viewing a read-only bundled example, while in read-only **Graph View** (`viewMode === 'graph'`), whenever a modal is open (`isModalOpen`, or any `[aria-modal="true"]` element), or when focus sits inside a `[data-native-undo="true"]` input (Scene Title, custom Staging header field, Source Find/Replace & Symbol Rename inputs, Library search/rename inputs, Version History milestone input, AI chat composer, AI Brief/Context forms, and AI Settings API key input).
- **Active-Draft Resync**: Stepping Undo/Redo increments `history.revision`, prompting memoized Live Mode editors (`StagingBlockCard`, `AestheticBlockEditor`, and `ExecutionBeatRow` via `useSubStateDrafts.ts`) to immediately resync their local drafts even while focused.

### Multi-Script Persistence, Version History & Crash-Recovery Mirror (`src/ui/useScriptLibrary.ts`, `src/ui/scriptLibraryDb.ts`, `src/ui/library/`, `src/ui/scriptSnapshots.ts`)
- **Mount Hydration, Fallback Reconciliation & Mirror Rescue**: On mount, `useScriptLibrary` (facade over `src/ui/library/useLibraryPersistence.ts`, `useLibrarySnapshots.ts`, and `useLibraryFileIO.ts`) snapshots the synchronous `localStorage` mirror (including `auteur-editor-mirror-updated-at-v1`), runs `scriptLibraryDb.reconcileFallbackStorage()` to automatically merge any stranded `localStorage` fallback scripts/snapshots back into IndexedDB and clear the fallback keys, runs `scriptLibraryDb.migrateFromLegacyLocalStorage()`, loads the IndexedDB library list, and reconciles via pure `reconcileHydratedScript()`—preserving newer mirrored edits or rescuing a custom script missing from IndexedDB before activating (falling back to `DEFAULT_PRESET` only when no matching custom script or mirror exists).
- **Resilient IndexedDB Retry, Immediate Structural Flushes & `localStorage` Mirror**: `scriptLibraryDb` (facade over `src/ui/library/idbTransactions.ts`, `fallbackStorage.ts`, `recordSanitizers.ts`, and `dbTypes.ts`) automatically drops stale/closed `IDBDatabase` handles and retries once before falling back (reserving permanent fallback lock-out strictly for `SecurityError`/`NotSupportedError`, logging a `console.warn` on fallback, and auto-merging pending fallback data whenever IndexedDB recovers mid-session). Typing and title edits debounce-save (`350ms`) to `scriptLibraryDb.put()`, while high-value structural commits (**Apply AI Draft**, **Apply AI Patch/Fix**, **Apply AI Title**, **Restore Snapshot**) plus `visibilitychange` (`hidden`), `pagehide`, script switches, backups, and unmount flush immediately (updating `lastSavedSnapshotRef` strictly *after* `put()` succeeds) while continuously calling `mirrorActiveScriptToLocalStorage()` so `ErrorBoundary` crash recovery stays intact. Bundled examples remain strictly read-only and never auto-create IndexedDB records until the user explicitly clicks **Fork to Edit** in `TopSlateBar` (or **Fork** in the Library).
- **AI-Triggered Version History & Manual Milestones (IndexedDB `v2` `snapshots` Store)**: `scriptLibraryDb` stores per-script plain-text `ScriptSnapshot` records in a dedicated `snapshots` object store indexed by `scriptId` (with full fallback backend support and atomic cascade delete on `delete`, `bulkDelete`, and `clearAll`). Empty/whitespace-only and consecutive identical auto-snapshots are skipped, and unprotected auto-snapshots cap at `MAX_AUTO_SNAPSHOTS_PER_SCRIPT = 30` per script (FIFO) while manual milestones and pinned snapshots are retained permanently. Restoring a snapshot auto-saves a `pre_restore` checkpoint and commits via `commitRawText(..., {mode: 'checkpoint'})` for instant single-step `Cmd/Ctrl+Z` undo; forking a snapshot pre-populates the new branch's `branchNote` (`Branched from snapshot: <label>`).

## 5. Programmatic JSON IR, Patch & Lens Slicer Layer

To support model-agnostic **Create**, **Edit**, and **Evaluate** pipelines without breaking **Plain-Text-as-Truth**, `src/core/` exposes a pure TypeScript + Zod programmatic interchange layer (fully specified in `docs/JSON_IR_SPEC.md`, with schema evolution tracked in `docs/SPEC_CHANGELOG.md`) with optional `ruleOverrides?: LintRuleOverrides` support across `toAuteurEnvelope()`, `compileAuteurDraft()`, `applyAuteurPatch()`, and `sliceAuteurScript()`:

- **Create**: `compileAuteurDraft(input, ruleOverrides?)` validates untrusted JSON drafts against `AuteurScriptDraftSchema`, compiles deterministically to canonical `v0.4.0` plain text via `fromAuteurIR()`, and returns Script Supervisor diagnostics.
- **Edit**: `applyAuteurPatch(rawText, patch, options)` (exposed via `src/core/patch.ts` over `src/core/patch/`) executes multi-op batches transactionally against snapshot-stable IDs (`MB#`, `MB#.#`, `S#`, `S#.#`) with optional `expectedSnapshotHash` concurrency checks, `ruleOverrides`, and a `rejectOnNewErrors` deterministic lint gate. `projectAuteurPatchPreview(rawText, patch)` (`src/core/patch/preview.ts`) reuses the same origin-tracked working IR loop purely (zero mutations) to map pre-patch Staging Macro-Block indices (`MB#`), Execution Macro-State indices (`S#`), and insertion seams to exact before/after text even across multi-op batches with inserts, deletes, and reorders.
- **Evaluate**: `sliceAuteurEnvelope()` / `sliceAuteurScript(rawText, specOrPreset, ruleOverrides?)` isolate arbitrary dimensions (plus 5 built-in `AUDIT_LENS_PRESETS`) paired with deterministically inherited `resolvedCamera.effectiveFraming`, and `validateAuteurReview()` validates structured findings with executable `suggestedPatch` payloads.
