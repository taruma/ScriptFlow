# Changelog

All notable changes to the **ScriptFlow** application (**Auteur Script Editor**) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> **Versioning Scope Note**
> - This file tracks **ScriptFlow application releases** (`1.0.0` pre-release UI/UX polish phase). `package.json` intentionally remains at `"0.4.0"` until the final `1.0.0` release tag is cut.
> - Changes to the platform- and model-agnostic **Pure Auteur Script (`v0.4.0`)** canonical inline grammar, deterministic Script Supervisor linter, and programmatic JSON IR specification are tracked separately in [`docs/SPEC_CHANGELOG.md`](docs/SPEC_CHANGELOG.md).

## [1.0.0] - Unreleased

### Changed
- **Theme-Aware Script Library Folder Combobox (`LibraryFolderCombobox`)**: Replaced the unstyled native `<datalist>` popup on the Project Folder input in `LibraryPreviewPane` with a custom, 4-theme-aware, keyboard-navigable combobox (`ArrowUp`/`ArrowDown`/`Enter`/`Escape` and click-to-toggle chevron) that lists all existing folders immediately on focus, filters while typing, offers 1-click creation for new folder names, and provides a `Remove from folder` action when assigned.
- **Unified Pre-Flight Script & Backup Import Modal (`ScriptImportModal`, `importPreflight.ts`)**: Consolidated `File ▾ → Import / Restore...` and `Library → Import` into a single-click, whole-modal drag-and-drop inspector (`aria-modal="true"`) supporting `.txt`, `.md`, `.markdown`, `AuteurEnvelope`, `AuteurScriptIR`, `AuteurScriptDraft`, and `auteur-script-library-backup` `.json` files. Evaluates `v0.4.0` structural fit, deterministic Script Supervisor lint diagnostics, and legacy/tagless/unstructured syntax warnings before writing to IndexedDB; surfaces content-hash duplicates (`#snapshotHash`) with 1-click **`Open Existing Script`** (and unchecks duplicate backup items by default across differing IDs); and supports both **`Import as New Script`** (with title collision warnings) and undoable **`Replace Current Script`** (with automatic `Pre-Restore` Version History snapshots).
- **Timestamped & Content-Hashed Export Filenames (`scriptLibraryCodec`, `agentContextCodec`)**: Standardized all 5 browser file exports to embed a sortable local `YYYYMMDD-HHMMSS` timestamp and full 8-character deterministic `computeSnapshotHash()` digest (`<slug>-YYYYMMDD-HHMMSS-<hash8>.txt`, `<slug>-YYYYMMDD-HHMMSS-<hash8>-tagless.txt`, `<slug>-YYYYMMDD-HHMMSS-<hash8>.json`, `auteur-library-backup-YYYYMMDD-HHMMSS-<hash8>.json`, and `auteur-agent-context-YYYYMMDD-HHMMSS-<hash8>.json`), placing `-tagless` at the end for clean sorting and updating `deriveTitleFromFilename()` to strip exported timestamp/hash suffixes on re-import.
- **Brand Identity, Header Logo Swap & Metadata (`TopSlateBar`, `AppInfoModal`, `index.html`, `public/`)**: Replaced the plain-text `"ScriptFlow"` / `"S"` header title with theme-adaptive, pixel-aligned `SCRIPTFLOW - BLACK.png` / `SCRIPTFLOW - WHITE.png` brand lockups (`h-7 md:h-8 lg:h-9`) on desktop/tablet and a compact `30×30px` theme-adaptive clapboard mark (`/android-chrome-192x192.png`) on `< 640px` viewports; added the brand lockup inside `AppInfoModal`; wired `/favicon.ico`, PNG favicons, `/apple-touch-icon.png`, and `/site.webmanifest`; and updated page titles, meta descriptions, and docs to **`Auteur Script Editor & Scene Blueprint`** (*Draft the World. Direct Every Beat.*).
- **Direct File Drop in Source Mode (`SourceEditor`, `resolveSourceDroppedFileContent`)**: Dragging and dropping a `.txt`, `.md`, `.markdown`, or `.json` (`AuteurEnvelope`, `AuteurScriptIR`, `AuteurScriptDraft`, or single/multi-script `auteur-script-library-backup` taking the first script) file directly onto the editable Source Mode editor immediately replaces `rawText` as a single undoable checkpoint—staying in Source Mode, preserving the current Scene Title, and staying disabled on read-only bundled examples.

### Architecture & Engineering Notes
- **Zero-React Pure Core & Plain-Text-as-Truth Pipeline**: Every module under `src/core/` is 100% pure TypeScript with zero React, DOM, `localStorage`, or CSS dependencies, deriving AST, extracted metadata, deterministic diagnostics, highlights, and JSON envelopes synchronously from `rawText`.
- **Modular Facade Architecture**: Codebase decomposed cleanly beneath preserved top-level `.ts`/`.tsx` facades across `src/core/patch/`, `src/services/knowledge/`, `src/services/tools/`, `src/services/gemini/`, `src/services/decisions/`, `src/ui/canvas/`, `src/ui/labels/`, `src/ui/library/`, `src/ui/ai/`, `src/ui/agentContext/`, `src/components/canvas/`, `src/components/ai/`, `src/components/library/`, `src/components/execution/`, and `src/components/debug/`, maintaining zero source files over 800 lines and 8 lazy-loaded Vite chunks (`AuteurGraphView`, `AiAssistantSidebar`, `AiBriefModal`, `AiContextInspectorModal`, `AiSettingsModal`, `AiTraceModal`, `VersionHistoryModal`, and `JsonIrDebugDrawer`).
- **Verification Baseline**: Verified against `30` Vitest test files (`npm test`), strict TypeScript checking (`npm run lint` / `tsc --noEmit`), and Vite production bundling (`npm run build`).
