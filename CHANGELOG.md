# Changelog

All notable changes to the **ScriptFlow** application (**Auteur Script Editor & Scene Blueprint**) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> **Versioning Scope Note**
> - This file tracks **ScriptFlow application releases** (`1.0.0` in `package.json`).
> - Changes to the platform- and model-agnostic **Auteur Script (`v0.4.0`)** canonical inline grammar, deterministic Script Supervisor linter, and programmatic JSON IR specification are tracked separately in [`docs/SPEC_CHANGELOG.md`](docs/SPEC_CHANGELOG.md).

## [Unreleased]

### Added
- **URL Deep-Linking (`/?example=`, `/?url=`, `/?agents=`) & Readable Example Slugs**:
  - Added readable `slug` identifiers in `src/data/examples/catalog.json` (`the-grand-continental`, `mark-and-lucas`, `balloon-panic`, `robert-machu-pichu`, `three-years-late-part-1`..`4`, `frequency-over-force-part-1`..`2`) and `getBundledExampleByIdOrSlug()` in `src/data/examples/index.ts`.
  - Added `src/ui/urlLaunch.ts` enforcing mutually exclusive single-action URL parameters (`?example=`, `?url=`, `?agents=`), `http:`/`https:` validation, `history.replaceState` query cleanup, and CORS/size-bounded remote text fetching.
  - On desktop (`>= 640px`), `/?url=<file-url>` fetches and pre-populates `ScriptImportModal` (pre-flight scorecard + Merge/New/Replace confirmation) and `/?agents=<json-url>` fetches and opens `AgentContextImportDialog` directly without auto-opening the AI sidebar.
  - On narrow viewports (`< 640px`), modals are skipped: `/?example=` and `/?url=` (opening as a read-only `'remote'` preview without modifying IndexedDB or `localStorage`) are accepted, while `/?agents=` is ignored with a toast.

## [1.0.0] - 2026-11-23

Initial public release of **ScriptFlow** (`v1.0.0`) supporting **Auteur Script `v0.4.0`**.

### Added

#### Live & Source Auteur Script Editor
- **Asymmetric `40/60` Two-Column Live Workspace (Resizable)**: Independently scrollable **Phase 1 — Staging (`S0`)** and **Phase 2 — Execution (`S1` → `SN`)** columns on desktop (`lg:`) with slim sticky headers, a draggable center divider (`25%`–`60%`, double-click or **Settings → Column layout → Reset** to restore `40/60`, persisted in `localStorage`), and single-column stacking on narrower viewports.
- **Structured `[AESTHETIC]` Lookbook & Pluggable Block Registry**: 2-column live-highlighted `Key: Value` editor (`AestheticBlockEditor`) registered via `src/components/stagingBlockRegistry.ts`, with hanging-indent token highlighting and collapsed key counts (`X keys`).
- **Always-Formatted `↳` Waterfall Sub-State Editing & 1-Based `S#.#` Indicators**: Live `->` / `→` / `Enter` Sub-State splitting, `Backspace`-at-start merging, `ArrowUp`/`ArrowDown` cross-Sub-State navigation, `Alt+↑`/`Alt+↓` (`Option+↑`/`Option+↓`) undoable keyboard Sub-State reordering with caret preservation, quiet pure-visual 1-based Sub-State badges (`S1.1`, `S1.2`, … aligned 1-to-1 with JSON IR, Patch ops, Quick Scan, and AI jump targeting; toggleable in **Settings → Sub-State IDs** with zero React re-renders), and camera continuity rails vs. dotted `cut` / `cut · recall` hairlines.
- **Surgical Management & Drag-and-Drop Reordering**: Hover-revealed `+` insertion seams, canonical/custom Macro-Block picker, collapsible Staging cards and Execution Macro-States with bulk `Collapse all` / `Expand all`, and keyboard-accessible `@dnd-kit` drag-and-drop reordering (`SortableList`) preserving per-item collapse state.
- **Global Paste-and-Hydrate & Document Undo/Redo**: Automatic multi-block Auteur Script paste hydration guarded against modals, read-only examples, and AI sidebar inputs; pure plain-text Undo/Redo stack (`src/core/history.ts`) with coalesced typing bursts, structural checkpoints, and active-draft `historyRevision` resync.
- **Source Mode, Find & Replace (Regex), Safe Symbol Rename, Direct Drop & Quick Format**: Centered single-document Source editor (`~820px`, `JetBrains Mono`) with collapsible **Find & Replace** (case-sensitive `Aa`, whole-word `W`, JavaScript Regex `.*` with `$1`/`$2`/`$&` backreferences and inline syntax-error alerts, `All` / `Staging` / `Execution` scope, zero-width-shift live overlay match highlighting + smooth auto-scroll inside `LiveHighlightedEditor`, `Enter`/`Shift+Enter`/`Esc` tray navigation, Find-only mode on read-only examples, and single-checkpoint Undo), **Safe Symbol Rename** (boundary-safe rename across Characters/speakers, `@ref` handles, `[AESTHETIC]` Lookbook Tokens, and `[CAM ##]` camera slots with live occurrence preview, syntax validation, collision-blocking guards, and single-checkpoint Undo), direct `.txt`/`.md`/`.json` file drop onto the editable Source editor to replace `rawText` as one undoable checkpoint, and non-destructive whitespace **Format Script** (`formatAuteurScript()`).
- **Streamlined Top Bar, Brand Lockups, Timestamped Exports & About Modal**: Theme-adaptive `SCRIPTFLOW - BLACK.png` / `SCRIPTFLOW - WHITE.png` horizontal brand lockups (plus favicons, `apple-touch-icon.png`, and `site.webmanifest`), tiered **`File ▾`** menu (`Script & History`: `New Blank Script`, `Duplicate Script`, `Import / Restore...`, `Format Script`, `Version History...`; `Export & Library`: `Download ▸` flyout for `Canonical .txt`, `Tagless .txt`, `JSON Envelope`, `Backup All Scripts`, `Browse Library...`; `Tools & Settings`: `JSON IR Inspector...`, `Settings`), matching **`Copy | ▾`** clipboard actions, standardized timestamped & content-hashed export filenames (`<slug>-YYYYMMDD-HHMMSS-<hash8>.*`, `auteur-library-backup-YYYYMMDD-HHMMSS-<hash8>.json`, and `auteur-agent-context-YYYYMMDD-HHMMSS-<hash8>.json`), and a far-right icon-only **`About`** button opening the lazy-loaded `AppInfoModal` (`ScriptFlow v1.0.0 · Auteur Script v0.4.0`, `MIT License`, documentation links, sister suite links, and Quick Editor Shortcuts).
- **Narrow-Viewport Read-Only Mode (`< 640px`)**: Automatically shifts phones and narrow split windows into a read-only Live Mode reader with the compact `30×30px` clapboard mark (`/android-chrome-192x192.png`), 1-tap icon-only Canonical Copy, compact Staging/Execution section headers retaining **`Collapse all` / `Expand all`**, collapsed right diagnostic gutters with symmetric horizontal margins, and a browse-and-open-only Script Library modal.
- **Read-Only Spatial Graph View (`[ Live | Graph | Source ]`)**: Lazy-loaded `@xyflow/react` pan-anywhere blueprint canvas (`src/components/canvas/AuteurGraphView.tsx`, backed by pure TS `src/ui/canvas/`, available on `>= 640px` tablets & desktops) with strictly locked cards (`draggable: false`, `selectable: false`), desktop scroll-wheel zoom + click-drag pan, touch-ready 1-finger pan & 2-finger pinch (`zoomOnDoubleClick={false}`, `paneDragThreshold={4}`, `touch-none overscroll-none`), mouse-only hover tracing, preserved drag-to-select text inside `Source` (`</>`) blocks, touch-sized `@media (pointer: coarse)` targets, and tablet-friendly defaults (`MiniMap` collapsed `< 1024px`). Features an orientation-aware **3-tier stratified layout** (**`L → R`** horizontal overview starting folded; **`T ↓ B`** 90° 3-column vertical deep-dive starting unfolded into sculpted Sub-State cards and `[AESTHETIC]` Key–Value lookbook mini-cards with **`Keys`/`Fold`** + opposite-side **`Source`** controls), strict tier boundaries with **cascading state-flow rounded orthogonal dashed pipes**, **Shot Chambers**, quiet `RECALL CAM ##` spine badges with on-demand stepped **`RECALL`** subway lanes, a **3-Anchor Canvas HUD** (`GraphHud`, Two-Tier `SubStateIsolatorDock` with `Ghost` / `Compact` modes & gliding SVG pulse-dot isolation, bottom-right Zoom / Fit / Map / **`?` Help popover**, and top-right read-only **Object Inspector** with Call Site `fitView` focus), always-ready **`Reset`**, and 4-theme parity.

#### Canonical `v0.4.0` Grammar, Live Script Supervisor & Bundled Examples
- **Lossless Parser, Highlighter & Metadata Extractor**: Full `v0.4.0` parser (`src/core/parser.ts`, including `parseDialogueModifiers()`), character-for-character lossless lexical & clause-underline tokenizer (`src/core/highlighter.ts`), and pure metadata extractor (`src/core/extractor.ts`) resolving `@ref` character bindings, `[AESTHETIC]` shorthand token dictionaries (with optional trailing `(reference: @ref)`), standalone Staging visual references, continuation context, Scene Topology inference (`inferSceneTopologyFromDocument()`), and camera transitions.
- **Live Deterministic Script Supervisor Linter**: 5 declarative pure rules in `LINT_RULE_REGISTRY` (`src/core/linter.ts`) covering `Lens 1`, `Lens 4`, and `Lens 5` (`viewport-coordinate-purity`, `camera-redefinition-guard`, `macro-state-resolution`, `multimodal-reference-isolation`, `frozen-first-frame-purity`), configurable per rule to `'off' | 'warning' | 'error'` in **Settings → Supervisor rules** and surfaced via zero-shift right-margin `DiagnosticDot` popovers.
- **6 Verbatim JSON Bundled Example Families (10 Scripts Total)**: Includes *The Grand Continental* (default), *Simit and River Pebbles*, *Cappadocia Balloon Panic*, *Robert's Machu Picchu Trail Dispatch*, and two multi-part branched `@video1` continuation series (*Three Years Late* and *Frequency Over Force* under `Video Continuation`) driven by non-destructive `src/data/examples/catalog.json` metadata overlays, read-only `Example` badges, collapsible Library & `Lineage Map` family views, and one-click **Fork to Edit**.

### Architecture & Engineering Notes
- **Zero-React Pure Core & Plain-Text-as-Truth Pipeline**: Every module under `src/core/` is 100% pure TypeScript with zero React, DOM, `localStorage`, or CSS dependencies, deriving AST, extracted metadata, deterministic diagnostics, highlights, and JSON envelopes synchronously from `rawText`.
- **Modular Facade Architecture**: Codebase decomposed cleanly beneath preserved top-level `.ts`/`.tsx` facades across `src/core/patch/`, `src/services/knowledge/`, `src/services/tools/`, `src/services/gemini/`, `src/services/decisions/`, `src/ui/canvas/`, `src/ui/labels/`, `src/ui/library/`, `src/ui/ai/`, `src/ui/agentContext/`, `src/components/canvas/`, `src/components/ai/`, `src/components/library/`, `src/components/execution/`, and `src/components/debug/`, with 10 lazy-loaded Vite chunks (`AuteurGraphView`, `AppInfoModal`, `ScriptImportModal`, `VersionHistoryModal`, `JsonIrDebugDrawer`, `AiAssistantSidebar`, `AiBriefModal`, `AiContextInspectorModal`, `AiSettingsModal`, and `AiTraceModal`).
- **Verification Baseline**: Verified against `30` Vitest test files (`347` tests via `npm test`), strict TypeScript checking (`npm run lint` / `tsc --noEmit`), and Vite production bundling (`npm run build`).
