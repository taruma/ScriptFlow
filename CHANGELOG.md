# Changelog

All notable changes to the **ScriptFlow** application (**Auteur Script Editor**) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> **Versioning Scope Note**
> - This file tracks **ScriptFlow application releases** (`1.0.0` pre-release UI/UX polish phase). `package.json` intentionally remains at `"0.4.0"` until the final `1.0.0` release tag is cut.
> - Changes to the platform- and model-agnostic **Pure Auteur Script (`v0.4.0`)** canonical inline grammar, deterministic Script Supervisor linter, and programmatic JSON IR specification are tracked separately in [`docs/SPEC_CHANGELOG.md`](docs/SPEC_CHANGELOG.md).

## [1.0.0] - Unreleased

### Added

#### Live & Source Auteur Script Editor
- **Asymmetric `40/60` Two-Column Live Workspace (Resizable)**: Independently scrollable **Phase 1 — Staging (`S0`)** and **Phase 2 — Execution (`S1` → `SN`)** columns on desktop (`lg:`) with slim sticky headers, a quiet draggable center divider (`25%`–`60%`, double-click or **Settings → Column layout → Reset** to restore default `40/60`, persisted in `localStorage`), and responsive single-column stacking on narrower viewports.
- **Structured `[AESTHETIC]` Lookbook & Pluggable Block Registry**: 2-column live-highlighted `Key: Value` editor (`AestheticBlockEditor`) registered via `src/components/stagingBlockRegistry.ts`, with hanging-indent token highlighting and clean collapsed header counts (`X keys`).
- **Always-Formatted `↳` Waterfall Sub-State Editing & 1-Based `S#.#` Indicators**: Live `->` / `→` / `Enter` Sub-State splitting, `Backspace`-at-start merging, `ArrowUp`/`ArrowDown` cross-Sub-State navigation, `Alt+↑`/`Alt+↓` (`Option+↑`/`Option+↓`) undoable keyboard Sub-State reordering with caret preservation, quiet pure-visual 1-based Sub-State badges (`S1.1`, `S1.2`, … aligned 1-to-1 with JSON IR, Patch ops, Quick Scan, and AI jump targeting, toggleable in **Settings → Sub-State IDs** with zero React re-renders), and camera continuity rails vs. dotted `cut` / `cut · recall` hairlines.
- **Surgical Management & Drag-and-Drop Reordering**: Hover-revealed `+` insertion seams, canonical/custom Macro-Block picker, collapsible Staging cards and Execution Macro-States with bulk `Collapse all` / `Expand all`, and keyboard-accessible `@dnd-kit` drag-and-drop reordering (`SortableList`) preserving per-item collapse state.
- **Global Paste-and-Hydrate & Document Undo/Redo**: Automatic multi-block Auteur Script paste hydration guarded against modals, read-only examples, and AI sidebar inputs; pure plain-text Undo/Redo stack (`src/core/history.ts`) with coalesced typing bursts, structural checkpoints, and active-draft `historyRevision` resync.

- **Narrow-Viewport Read-Only Mode (`< 640px`)**: Automatically shifts phones and narrow split windows into a read-only Live Mode reader with a compact **`S`** brand mark, uneditable Scene Title, hidden `File` / `[ Live | Graph | Source ]` / Undo-Redo / `AI` chrome, 1-tap icon-only Canonical Copy, compact Staging/Execution section headers retaining **`Collapse all` / `Expand all`**, collapsed right diagnostic gutters with symmetric horizontal margins, and a browse-and-open-only Script Library modal.
- **Read-Only Spatial Graph View (`[ Live | Graph | Source ]`)**: Lazy-loaded `@xyflow/react` pan-anywhere blueprint canvas (`src/components/canvas/AuteurGraphView.tsx`, backed by pure TS `src/ui/canvas/`, available on `>= 640px` tablets & desktops while mobile `< 640px` reverts to read-only Live Mode) with strictly locked cards (`draggable: false`, `selectable: false`, and stripped `position` changes so dragging directly over cards pans cleanly), desktop scroll-wheel zoom + click-drag pan, touch-ready 1-finger pan & 2-finger pinch (`zoomOnDoubleClick={false}`, `paneDragThreshold={4}`, `touch-none overscroll-none`), mouse-only hover tracing (`pointerType === 'mouse'`), preserved drag-to-select text inside `Source` (`</>`) blocks (`nopan select-text`), `@media (pointer: coarse)` touch-sized HUD/card targets, and tablet-friendly defaults (`MiniMap` collapsed by default `< 1024px`). Structured as an orientation-aware **3-tier stratified layout** (**`L → R`** horizontal overview starts folded for both Execution Macro-States and `[AESTHETIC]` Lookbook cards; **`T ↓ B`** 90° 3-column vertical deep-dive starts unfolded into sculpted Sub-State cards and distinct `[AESTHETIC]` Key–Value Lookbook swatch mini-cards with generous spacing, ruler-straight horizontal Sub-State chains, and **`Keys`/`Fold`** + opposite-side **`Source`** controls). #### Canonical `v0.4.0` Grammar & Live Script Supervisor
- **Lossless Parser, Highlighter & Metadata Extractor**: Full `v0.4.0` parser (`src/core/parser.ts`, including `parseDialogueModifiers()`), character-for-character lossless lexical & clause-underline tokenizer (`src/core/highlighter.ts`), and pure metadata extractor (`src/core/extractor.ts`) resolving `@ref` character bindings, `[AESTHETIC]` shorthand token dictionaries (with optional trailing `(reference: @ref)`), standalone Staging visual references, continuation context, Scene Topology inference (`inferSceneTopologyFromDocument()`), and camera transitions.

#### Appearance, Accessibility & Safeguards
- **4-Mode Semantic Theme System & Display Controls**: **Light** (*Clean Warm Stone*), **Warm** (*Drafting Paper*), **Dark** (*Warm Obsidian Studio*, default), and **Pure Black** (*OLED Blueprint Void*) powered exclusively by semantic CSS variables and `UI_TOKENS`, plus script text-size presets (`13px`–`16px`), toggleable monochrome clause underlines, and toggleable 1-based Execution Sub-State ID badges (`Sub-State IDs`, On by default).

### Architecture & Engineering Notes
- **Zero-React Pure Core & Plain-Text-as-Truth Pipeline**: Every module under `src/core/` is 100% pure TypeScript with zero React, DOM, `localStorage`, or CSS dependencies, deriving AST, extracted metadata, deterministic diagnostics, highlights, and JSON envelopes synchronously from `rawText`.
- **Modular Facade Architecture**: Codebase decomposed cleanly beneath preserved top-level `.ts`/`.tsx` facades across `src/core/patch/`, `src/services/knowledge/`, `src/services/tools/`, `src/services/gemini/`, `src/services/decisions/`, `src/ui/canvas/`, `src/ui/labels/`, `src/ui/library/`, `src/ui/ai/`, `src/ui/agentContext/`, `src/components/canvas/`, `src/components/ai/`, `src/components/library/`, `src/components/execution/`, and `src/components/debug/`, maintaining zero source files over 800 lines and 8 lazy-loaded Vite chunks (`AuteurGraphView`, `AiAssistantSidebar`, `AiBriefModal`, `AiContextInspectorModal`, `AiSettingsModal`, `AiTraceModal`, `VersionHistoryModal`, and `JsonIrDebugDrawer`).
- **Verification Baseline**: Verified against `29` Vitest test files (`npm test`), strict TypeScript checking (`npm run lint` / `tsc --noEmit`), and Vite production bundling (`npm run build`).
